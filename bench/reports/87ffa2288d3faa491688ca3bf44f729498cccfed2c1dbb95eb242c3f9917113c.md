**`src/server.py:556`** — A generation error in the streaming path races the player thread and can mark a *failed* message `"completed"` with an `audio_file` path that was never written. `streaming_chunk_iter` is a lazy generator, so `VoxtralEngine.generate`'s `ValueError` (`src/tts/engine.py:131`) surfaces inside `play_stream`. `play_stream`'s `finally` still pushes the `None` sentinel (`src/tts/player.py:355`), the player thread sees a zero-chunk stream, skips `save_audio`, and calls `on_complete(job.output_path)` (`src/tts/player.py:249`) → status `"completed"` (`src/server.py:510`).
